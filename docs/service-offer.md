# Upwork Project Catalog services

## Single AI PR Evidence Review

[View the PR evidence review on Upwork](https://www.upwork.com/services/product/development-it-engineer-review-of-an-ai-generated-pull-request-and-its-ci-evidence-2126294195508005988)

**Description** — Get an engineer-reviewed report for one GitHub pull request before you decide whether to merge. I compare the change to your acceptance criteria, review its test coverage and check whether available CI and execution evidence applies to the exact revision. The report includes prioritized findings, the evidence behind them and any remaining checks you need to make.

**Starter** — US$99, 3 days. One PR with up to 500 effective changed code lines, reviewed using existing authorized evidence.

**Buyer requirements** — Provide the PR or a redacted patch, base and head SHA, requirements, relevant check URLs or redacted logs, and any known gaps. Confirm which repository and material may be reviewed. Private access, if needed, uses least-privilege access through the agreed repository interface. Share customer data only through agreed, authorized channels and remove secrets from all materials.

**Deliverables** — An owner-reviewed Markdown and PDF report with the reviewed revision and scope, findings with file references, evidence for CI and test claims, relevant limitations, and practical verification steps. Code changes, repository-wide review, production access, penetration tests and merge operations are outside the offer. If evidence is incomplete or stale, the report records what can be verified and what remains open.

## AI Agent Acceptance Review

[View the agent acceptance review on Upwork](https://www.upwork.com/services/product/development-it-an-acceptance-review-of-your-ai-agent-workflow-2126299378731342513)

**Description** — Get an engineer-reviewed evaluation for one agent workflow. I examine defined tasks and outcomes, assess available run evidence and identify failures, gaps and the cases that need a new run. Each case has an expected behavior, an outcome and a reference to supporting evidence.

**Starter** — US$199, 5 days. One workflow and up to five acceptance cases.

**Buyer requirements** — Provide the workflow, agent/version, expected results, redacted logs or synthetic fixtures and any relevant constraints. Isolated live runs require prior agreement on the environment, permitted tool actions and expected state changes. Explicitly authorized cases can assess retry, recovery or output handling using controlled inputs and read-only or reversible effects.

**Deliverables** — An owner-reviewed Markdown report with case-level PASS, FAIL, BLOCKED or NOT_RUN, evidence links or redacted excerpts, and prioritized remediation. Production access, unrestricted tool runs and irreversible actions are outside the offer.

See the [sample PR evidence report](../examples/sample-review-report.md).
