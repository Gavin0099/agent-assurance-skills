# PR evidence review

## Review target

- Repository and PR or local input
- Requirements source and review scope
- Target tip, comparison base, reviewed head, and head observed before reporting
- Review status and evidence limitations

## Findings

List verified findings in severity order. Provide impact, path and line at the reviewed revision, supporting evidence, and reproduction steps or static reasoning. Use critical for credible catastrophic impact, high for a major regression or contract violation, medium for a material but narrower effect, and low for a minor actionable defect. State when reproduction was unexecuted. If none were verified, state that here.
